# Page d’accueil — Enquête ESIBA

Interface web d’accueil conçue pour présenter une enquête et inviter les visiteurs à commencer le questionnaire. Le projet utilise le logo de l’ESIBA, une navigation et des textes animés.

## Fonctionnalités présentes

- Barre de navigation avec liens vers les pages du site ESIBA.
- Présentation de l’enquête.
- Animation de texte à effet machine à écrire.
- Menu de navigation mobile avec bouton burger.
- Mise en page HTML et CSS.

## Technologies

- HTML5
- CSS3
- JavaScript natif

## Lancer le projet

Aucune installation n’est nécessaire.

```bash
git clone https://github.com/donas9269/ESIBA_page_de_questionaire.git
```

Ouvre le fichier `index.html` dans ton navigateur.

## Point à vérifier

Le bouton « Commencer l’enquête » pointe vers `questionnaire.html`. Ce fichier n’apparaît pas dans la version actuelle du dépôt ; il faudra l’ajouter ou adapter le lien pour que le parcours soit complet.
